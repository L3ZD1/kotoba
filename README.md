## ⛩️ О проекте

**Kotoba (言葉)** — образовательная веб-платформа, созданная для тех, кто хочет изучать японский язык и постепенно достигать новых языковых уровней.

Наша цель — сделать изучение японского более доступным, интересным и структурированным.

## ✨ Возможности

| Возможность | Описание |
|:---|:---|
| 📖 Лексика | Изучение японских слов и выражений |
| 🈶 Кандзи | Знакомство с японскими иероглифами и их значениями |
| 📚 Грамматика | Изучение грамматических конструкций |
| 🎯 Упражнения | Закрепление полученных знаний |
| 🌸 Удобный интерфейс | Комфортное изучение языка |

## 🎌 Для кого предназначен Kotoba?

- Для начинающих, которые только знакомятся с японским.
- Для изучающих уровни JLPT N5–N1.
- Для тех, кто хочет расширить словарный запас.
- Для всех, кто интересуется японским языком и культурой.

## 🎨 Название

**言葉 (ことば, Kotoba)** — японское слово, означающее «слово», «речь» или «язык».

Название отражает основную идею проекта: изучение языка начинается со слов.
